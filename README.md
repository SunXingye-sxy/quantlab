# quantlab · A 股单因子回测框架

一个从零搭建的量化研究工具箱：数据管道 → 因子计算 → 分层回测 → 绩效评估。
面向 A 股日频数据，强调「可复现」与「无未来函数」。

## 进度

- [x] 数据管道（akshare 下载、前复权、本地 parquet 缓存、停牌剔除）
- [x] 因子计算（动量 / 反转，MAD 去极值、z-score 标准化）
- [x] 分层回测（五分组、交易成本、调仓周期敏感性）
- [x] 绩效指标（年化收益、Sharpe、最大回撤、换手率、IC）

## 快速开始

```bash
# 1. 安装依赖（建议先建虚拟环境）
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt

# 2. 下载数据（首次约 1–2 小时，取决于网络）
python scripts/download_data.py --limit 20   # 先小样本验证链路
python scripts/download_data.py              # 全量沪深300，2018-2024

# 3. 数据体检
python scripts/check_data.py

# 4. 构造因子并检验 IC
python scripts/build_factors.py

# 5. 分层回测 + 调仓周期敏感性 + 出图
python scripts/run_backtest.py
```

数据缓存在 `data/`（已被 `.gitignore` 排除），换电脑后需重新执行下载脚本。

## 数据治理

数据质量决定了因子研究的上限。处理原则与实测结果如下。

1. **前复权**：统一用 `adjust="qfq"`，否则除权日会出现假暴跌，污染因子与回测。

2. **涨跌幅重算**：接口返回的 `pct_chg` 按未调整除权的价格计算，高分红股在除息日会出现
   超过跌停的假暴跌（实测 601225 陕西煤业有 484 个交易日）。因此一律用前复权收盘价
   `pct_change()` 重算，不使用接口字段。

3. **数据源交叉验证**：东方财富的前复权序列在部分高送转标的上复权因子断裂，价格本身
   不连续（600039 四川路桥 386 天、601088 中国神华 309 天出现 >10.5% 的跳空），
   而新浪同标的数据越界 0 条。故主源用新浪，东财仅作兜底。

4. **双源 + 缓存兜底**：东财 push2 在代理环境或高频请求下会被限流，自动切新浪；
   pyarrow 不可用时降级 pickle，保证数据一定落地、能读回。

5. **停牌剔除**：成交量为 0 的记录不参与计算。

6. **交易日历**：用真实开市日，不把节假日当缺失。

7. **接口版本兼容**：akshare 1.20.45+ 重命名了多个接口
   （`tool_trade_date_hist_sina` → `calendar_trade_date_hist_sina`，
   `stock_zh_a_daily` → `stock_zh_a_hist_sina`，
   `stock_zh_a_hist` → `stock_zh_a_hist_em`）。代码按候选名依次探测，新旧版本均可运行。

8. **已知局限**：当前使用最新成分股名单，**存在幸存者偏差**（未使用 point-in-time
   成分股名单）。成分股名单每年 6 月、12 月调仓，不同时点运行得到的股票数会不同。

一次完整运行的实测结果：**287 只 / 445,524 条 / 1,699 个交易日**，
日期范围 2018-01-02 ~ 2024-12-31，样本覆盖率 91.4%（缺失来自停牌、退市与上市晚），
涨跌幅越界仅 2 条（均为新股首日，正常）。

板块分布：沪市主板 159 只、深市主板 76 只、创业板 32 只、科创板 19 只、其他 1 只。

## 因子

三个单因子，全部按日截面处理，不含未来信息。

| 因子 | 定义 | 经济含义 |
|---|---|---|
| `mom_20` | `close[t-1] / close[t-21] - 1` | 20 日中期动量 |
| `mom_60` | `close[t-1] / close[t-61] - 1` | 60 日中期动量 |
| `rev_5` | `-(close[t] / close[t-5] - 1)` | 5 日短期反转 |

三个设计要点：

1. **动量跳过最近 1 日（`skip=1`）**。A 股短期（1–5 日）存在明显的反转效应，
   昨天涨停的股票今天往往回落。若动量直接用「T 日收盘 / 60 天前收盘」，短期反转
   会污染真实的趋势信号。标准做法是用 T-1 到 T-60 的区间，避开最近一天的噪声。

2. **MAD 去极值，而不是 3σ**。按均值 ± 3σ 截断依赖均值与标准差，而这两者本身就被
   极值污染（一个涨停就能把标准差拉大）。MAD（中位数绝对偏差）用中位数做锚，
   对极值不敏感，正态下 `σ ≈ 1.4826 × MAD`，本项目取 5 倍 MAD 缩尾。
   注意是 **clip 而非 drop**：极端值压到边界，样本量不变。

3. **z-score 标准化**，使不同因子可比较、可合成，也让因子值变成「相对全市场的排名位置」。

IC 检验（因子值与次日收益的截面 Spearman 相关，287 只样本）：

| 因子 | 有效日数 | 日均覆盖 | 缺失率 | IC 均值 | ICIR | t 值 |
|---|---|---|---|---|---|---|
| `mom_20` | 1678 | 265 | 10.1% | -0.011 | -0.05 | -2.10 |
| `mom_60` | 1638 | 264 | 12.4% | -0.004 | -0.02 | -0.63 |
| `rev_5` | 1694 | 266 | 9.0% | **+0.023** | 0.11 | **+4.63** |

短期反转因子统计显著，60 日动量完全不显著——这与 A 股散户主导、短期反转强于
中期动量的经验事实一致。

## 回测方法与假设

1. **信号错位（无未来函数）**：T 日收盘才拿得到 T 日因子，不可能当天成交。
   因此信号一律 `shift(1)`：T 日因子 → T+1 日成交 → 吃 T+1 的收益。
   少这一行，年化收益会凭空多出十几个点。

2. **分组按当日截面百分位重排**：不使用全样本排名，否则同一因子值在牛市可能进 G5、
   在熊市进 G1，分组含义随市场漂移。

3. **组内等权**：单因子研究要看因子的纯效应，等权可避免市值加权带来的市值暴露。

4. **交易成本按权重变化计费**：`sum(|w_t − w_{t-1}|) × 单边费率`，而不是按调仓次数
   拍一个常数。低换手因子少扣、高换手因子多扣，才是公平比较。单边费率取 0.1%
   （佣金 + 印花税 + 滑点合计，保守估计）。

5. **不做行业与市值中性化**：这是后续项目的内容。因此分组收益包含显著的市值与
   波动率暴露，**判断因子好坏只能看对冲后的多空组合，不能看单一分组的绝对收益**。

## 回测结果与结论

五分组分层回测，287 只沪深300成分股，2018-01-02 ~ 2024-12-31，单边成本 0.1%。

调仓周期敏感性（多空组合 = G5 减 G1）：

| 因子 | 调仓周期 | 多空年化 | 多空夏普 | 最大回撤 | 日均换手 |
|---|---|---|---|---|---|
| `mom_20` | 1 日 | +0.85% | 0.153 | 33.5% | 0.321 |
| `mom_20` | 5 日 | -0.75% | 0.080 | 33.1% | 0.146 |
| `mom_20` | 20 日 | -2.85% | -0.027 | 59.6% | 0.074 |
| `mom_60` | 1 日 | +1.47% | 0.181 | 47.8% | 0.081 |
| `mom_60` | 5 日 | +1.03% | 0.162 | 47.5% | 0.041 |
| `mom_60` | 20 日 | -0.11% | 0.110 | 55.0% | 0.048 |
| `rev_5` | 1 日 | -8.87% | **-0.333** | 64.6% | **0.720** |
| `rev_5` | 5 日 | +0.48% | 0.124 | 52.6% | 0.316 |
| `rev_5` | 20 日 | **+2.95%** | **0.247** | 41.3% | **0.077** |

三条结论：

1. **交易成本主导弱因子的生死**。`rev_5` 日频换手 0.720，年化成本约 18%，远超其
   alpha，扣费后年化 -8.87%；降至月频后换手 0.077，收益翻正为 +2.95%。
   同一个因子、同一份数据，仅改变调仓频率就完成从负到正的翻转。

2. **调仓频率必须匹配信号半衰期**。`mom_20` 在 1 日调仓下夏普 0.153 最优，
   但在 20 日调仓下转为 -0.027：其信号窗口只有 20 日，持仓一个月不动时用的是
   一个月前的排序，信号已失效。`mom_60` 衰减慢，20 日调仓仍有 0.110。

3. **三个因子均未达到可交易标准**。多空夏普最高为 `rev_5` 月频的 0.247，低于 0.5
   的经验阈值。单因子在 A 股的边际收益有限，需多因子合成与中性化处理（见后续项目）。

**一个容易误读的地方**：各因子 G1 与 G5 的年化收益多为正（8%–18%），中间三组为负，
呈 U 型而非单调。这不是因子有效，而是极端组（涨最多、跌最多）往往对应高波动的
中小市值股票，2019–2021 的小盘行情使其获得 beta 收益。判断因子只能看对冲后的多空组合。

图表见 `results/figures/`：各因子五组净值曲线、分组年化收益柱状图、
多空组合 1 日与 20 日调仓对比。

## 复现性

为减少「换台机器跑出不同结果」的风险：

- `requirements.txt` 中 `akshare` 建议钉住版本（接口改名频繁，见数据治理第 7 条）；
- 数据下载带缓存，重跑只补缺失的股票，不重复请求接口；
- 因子与回测全部向量化，不依赖随机数，同一份数据必然得到同一结果；
- 结果表落盘到 `results/tables/`，便于逐次对比。
