# quantlab · A 股单因子回测框架

一个从零搭建的量化研究工具箱：数据管道 → 因子计算 → 分层回测 → 绩效评估。
面向 A 股日频数据，强调「可复现」与「无未来函数」。

## 进度

- [x] 数据管道（akshare 下载、前复权、本地 parquet 缓存、停牌剔除）
- [ ] 因子计算（动量 / 反转，MAD 去极值、z-score 标准化）
- [ ] 分层回测（五分组、月度调仓、交易成本）
- [ ] 绩效指标（年化收益、Sharpe、最大回撤、换手率、IC）

## 快速开始

```bash
# 1. 安装依赖（建议先建虚拟环境）
python -m venv .venv
# Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 2. 下载数据（首次约 5-15 分钟，取决于网络）
python scripts/download_data.py --limit 20   # 先小样本验证链路
python scripts/download_data.py              # 全量沪深300，2018-2024

# 3. 数据体检
python scripts/check_data.py
```

数据缓存在 `data/`（已被 `.gitignore` 排除），换电脑后需重新执行下载脚本。

## 数据治理

1. **前复权**：用 `adjust="qfq"`，否则除权日会出现假暴跌。
2. **涨跌幅重算**：接口返回的 `pct_chg` 按未调整除权的价格计算，高分红股在除息日会出现超过跌停的假暴跌（实测 601225 陕西煤业有 484 个交易日）。因此一律用前复权收盘价 `pct_change()` 重算，不用接口字段。
3. **数据源交叉验证**：东财的前复权序列在部分高送转标的上复权因子断裂，价格本身不连续（600039 四川路桥 386 天、601088 中国神华 309 天出现 >10.5% 的跳空），而新浪同标的数据越界 0 条。故主源用新浪，东财仅作兜底。
4. **双源 + 缓存兜底**：东财 push2 在代理环境或高频请求下会被限流，自动切新浪；pyarrow 不可用时降级 pickle，保证数据一定落地、能读回。
5. **停牌剔除**：成交量为 0 的记录不参与计算。
6. **交易日历**：用真实开市日，不把节假日当缺失。
7. **已知局限**：当前使用最新成分股名单，**存在幸存者偏差**（未使用 point-in-time 成分股名单）。

最终体检结果：298 只 / 462,983 条 / 1699 个交易日，涨跌幅越界仅 2 条（新股首日，正常），覆盖率 91.4%（缺失来自停牌、退市与上市晚）。
